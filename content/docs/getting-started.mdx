# Getting started

After the reboot, log in and start Hyprland. The **welcome card** comes up by
itself the first time the shell starts and offers a guided tour of the real
panels. To see it again:

```bash
ashen ipc welcome open
ashen ipc tour start
```

## Keys

| Keys | Action |
|---|---|
| `SUPER` (tap) | launcher |
| `SUPER + SHIFT + W` | wallpaper picker (drives dynamic theming) |
| `SUPER + I` | settings |
| `SUPER + T / E / W / C` | terminal, files, browser, editor |
| `SUPER + Q` | close the window |
| `SUPER + F` / `SUPER + SHIFT + F` | fullscreen / float |
| `SUPER + N` | notifications |
| `SUPER + SHIFT + S` | screenshot |
| `SUPER + SHIFT + R` | start / stop screen recording |
| `SUPER + SHIFT + T` | timer: stopwatch, countdown, pomodoro |
| `SUPER + SHIFT + D` | arrange desktop widgets |
| `ALT + Tab` | window switcher |
| `SUPER + L` | lock |
| `SUPER + Escape` | power menu |
| `SUPER + 1…0` / `SUPER + ALT + 1…0` | go to / send the window to a workspace |

Every key can be changed from **Settings → Input**. The full list is in the
[Usage](/docs/usage/).

## Update

Run `ashen update`. Your own overrides live in `~/.config/ashen/`.
